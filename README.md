## 📖 About
This repository is my personal programming library.
Instead of collecting random notes, I document every concept I Learn in a structured
and detailed way. Each topic contains explanations, examples, best practices and practical use cases.

The goal is not just to remember syntax, but to truly understand how technologies work
and to build a reference that i can revisit throughout my carrer.

## 🎯 Goals
- Build a long-term programming knowledge base
- Learn concepts instead of memorizing code
- Document everything in my own words
- Create reusable examples and best practices
- Track my progress as a software developer
